Acting on an estimate of the present

A two-joint arm reaching under a sensory delay. Watch where the controller thinks its hand is, where its senses say it is, and where it actually is.

Sensory signals about the body arrive late. A controller that knows how its own body responds to commands does not have to wait for them: it can take the last state its senses reported and run that state forward through the commands it has issued since. Feedback still matters, but its job changes — it corrects the movement in progress and recalibrates the model that does the steering.

The plant. A two-joint planar arm with real inertia, and with the interaction torques that make one joint's motion disturb the other. The controller plans a straight, smooth hand path and tracks it. Its senses are late.

The two jobs the model does. It runs the arm forward from the last sensed state through the commands issued since, which is how the controller gets a current estimate to act on. And it says what force the hand is about to meet, which the controller cancels in advance. Both jobs use the same learned weights, and the same delayed error recalibrates them.

What is learned. Thirty-six overlapping tuning functions spanning hand velocity, each carrying a force vector. What trains them is the gap between the acceleration the model predicted and the acceleration that actually happened — a gap that can only be measured once feedback arrives, one delay late. Updates are applied in batches, at a rate divided by the number of corrections still in flight; learn faster than that and the delayed error chases its own tail. Learning asymptotes a little short of a perfect match, because thirty-six tuning functions can only approximate a smooth field and because the anticipatory push is computed from the planned velocity rather than the actual one.

Corrections in flight. Because every error is one delay old, corrections computed from it are still on their way when the next one is computed. The module divides the learning rate by how many are outstanding. Allow for corrections in flight switches that divisor off, which is the only way to see what delayed learning does without it.

Damage does not delete the model. It shortens how far forward the controller can run it, withdraws the compensation for the velocity-dependent interaction torques, withdraws the anticipation of learned external forces, and slows learning. What it leaves intact is the inertia model, which is why the result is a reach that bows, overshoots and shakes on arrival rather than one that fails outright.

Implementation. Forward Euler at a 2 ms step. The state estimate is an open-loop rollout, not a statistically weighted estimate, and it uses the same equations as the plant, so with no noise in the module a longer horizon costs almost nothing. Real prediction error compounds with the horizon; that is the main reason this module makes prediction look cheaper than it is.
