Rule 110: the entire local rule

1Seek A. Each growth cone turns toward increasing concentration of cue A.
2Avoid B. A repulsive cue bends the trajectory away from B.
3Branch conditionally. Branch when cue C is high enough and the branch is old enough.
4Stop locally. Stabilize when a branch reaches a permissive target zone; otherwise stop at its lifetime limit.

What to notice

The rule does not contain a picture of the final pattern. It specifies what each cell does given its local neighborhood.

Lecture prompt: If I wanted to transmit this entire endpoint literally, how much would I have to say compared with transmitting the rule that generated it?

Important distinction

The large number shown for the endpoint is a naive literal description length (for example, one bit per displayed cell). It is not a claim that the generated pattern itself has high Kolmogorov complexity. A short generator is evidence of the opposite.
